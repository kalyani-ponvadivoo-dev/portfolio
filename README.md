# Personal Portfolio Website

## About the Project

This is my personal portfolio website created using HTML and CSS. It introduces me as a Web Developer and showcases my interests, projects, and social media profiles.

## Features

- Home page with personal introduction
- About Me section
- My Interests section
- My Projects section
- Contact page with a contact form
- Instagram and LinkedIn profile links
- Google Fonts integration using the Outfit font

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Project Structure

```text
portfolio/
├── index.html
├── contact.html
├── style.css
└── README.md
```

## How to Run the Project

1. Clone this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Click the Contact link to navigate to the contact page.

## Pages

- **Home Page:** Displays my introduction, interests, and projects.
- **Contact Page:** Contains a form for entering a name, email address, and message.
